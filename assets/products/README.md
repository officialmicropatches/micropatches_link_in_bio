# Product Photo Folder

Place real MicroPatches product photos in this folder.

The page currently looks for these file names from `siteConfig.json`:

- `product_fhp_keychain.jpg`
- `product_lapd_keychain.jpg`
- `product_lafd_keychain.jpg`
- `product_75th_ranger_keychain.jpg`
- `product_chicago_pd_keychain.jpg`
- `product_phoenix_pd_keychain.jpg`
- `product_pomona_pink_keychain.jpg`
- `product_airborne_keychain.jpg`

Use lowercase file names, underscores, and no spaces. File name capitalization matters on GitHub Pages.

If an image is missing, the site shows `product_photo_placeholder.svg` instead.
